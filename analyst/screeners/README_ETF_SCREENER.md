# ETF动量筛选器使用指南

## 概述

ETF动量筛选器是一个专门用于筛选具有良好动量和趋势特征ETF的工具。它通过多维度的技术指标分析，帮助投资者发现当前市场中表现强劲的ETF产品。

## 核心功能

### 📊 多维度分析指标

1. **动量指标（权重35%）**
   - 1、3、6、12个月收益率
   - RSI相对强弱指标
   - MACD动量指标

2. **趋势指标（权重35%）**
   - 多周期均线排列
   - 趋势强度分析
   - 唐奇安通道位置

3. **成交量指标（权重15%）**
   - 成交量比率
   - 成交量趋势
   - 流动性检查

4. **质量指标（权重15%）**
   - 最大回撤控制
   - 波动率分析
   - 夏普比率评估

### 🎯 智能筛选逻辑

- **综合评分系统**：0-1分制，A+级为0.9分以上
- **多重过滤条件**：动量和趋势必须同时通过
- **质量控制**：风险指标限制确保投资安全
- **分类筛选**：支持按ETF类型定向筛选

## 使用方法

### 1. 环境配置

```bash
# 设置Tushare Token
export TUSHARE_TOKEN=your_tushare_token
```

### 2. 快速开始

```bash
# 查看帮助
python bin/screen_etfs.py --help

# 筛选宽基和行业ETF（推荐）
python bin/screen_etfs.py --types broad_market sector --max-etfs 20

# 筛选所有类型ETF
python bin/screen_etfs.py --max-etfs 30 --save

# 分析单只ETF
python bin/screen_etfs.py --single 510300.SH

# 查看筛选配置
python bin/screen_etfs.py --config-show
```

### 3. 高级用法

```bash
# 筛选特定类型并保存结果
python bin/screen_etfs.py --types thematic sector --max-etfs 15 --save

# 专注主题投资机会
python bin/screen_etfs.py --types thematic --max-etfs 10

# 海外配置机会
python bin/screen_etfs.py --types international --max-etfs 8
```

## 筛选标准详解

### 📈 动量标准（必须满足60%以上条件）

- **短期动量**：1个月收益率 ≥ 3%
- **中期动量**：3个月收益率 ≥ 8%
- **长期动量**：6个月收益率 ≥ 15%，12个月收益率 ≥ 20%
- **技术指标**：RSI在40-80区间，MACD直方图为正值

### 📊 趋势标准（必须满足50%以上条件）

- **均线排列**：MA5 > MA20 > MA60
- **价格位置**：当前价格 > MA20
- **趋势强度**：≥ 0.6（基于均线排列计算）
- **通道位置**：在唐奇安通道上方70%位置

### 📊 成交量标准（必须满足40%以上条件）

- **成交量比率**：≥ 1.0（相对20日均量）
- **流动性**：日均成交量 ≥ 100万
- **成交量趋势**：呈上升趋势

### 🛡️ 质量标准（必须满足40%以上条件）

- **风险控制**：最大回撤 ≤ 25%
- **波动率**：年化波动率 ≤ 40%
- **收益质量**：夏普比率 ≥ 0.5

## 输出解读

### 筛选结果表格
```
✅  1  510300.SH     沪深300ETF           broad_market   得分: 0.856 |
    动量: 0.85 | 趋势: 0.92 | 成交量: 0.80 | 质量: 0.75
```

- **✅/❌**：是否通过筛选
- **综合得分**：0-1分制，越高越好
- **分项得分**：各维度得分，可以看出强弱项

### 评级系统
- **A+级**（≥0.9）：顶级ETF，强烈推荐
- **A级**（≥0.8）：优秀ETF，值得关注
- **B+级**（≥0.7）：良好ETF，可以考虑
- **B级**（≥0.6）：合格ETF，谨慎考虑
- **C级**（≥0.5）：一般ETF，建议观望
- **D级**（<0.5）：较差ETF，不建议投资

## 投资建议

### 🎯 选择策略
1. **优先级排序**：综合得分 > 0.8的ETF优先考虑
2. **分散投资**：不要集中投资单一行业或主题
3. **动态调整**：每周复查一次，及时调整持仓
4. **风险控制**：关注最大回撤，设置止损点

### 💡 使用技巧
1. **市场环境**：牛市关注动量，震荡市关注质量
2. **配置比例**：宽基ETF做底仓，行业ETF做卫星
3. **时机选择**：结合市场情绪和政策导向
4. **持仓监控**：定期检查成交量和趋势变化

### ⚠️ 风险提醒
1. **历史表现不代表未来**：技术指标有滞后性
2. **市场风险**：系统性风险无法通过筛选规避
3. **流动性风险**：部分ETF可能存在流动性不足
4. **跟踪误差**：ETF可能偏离标的指数表现

## 常见问题

### Q: 为什么某些知名ETF没有通过筛选？
A: 筛选器专注于动量和趋势，价值型或防御型ETF可能不符合动量标准。

### Q: 筛选结果应该多久更新一次？
A: 建议每周更新一次，重大市场变化时可以随时更新。

### Q: 如何处理数据获取失败的情况？
A: 检查网络连接和Tushare Token，必要时使用备用数据源。

### Q: 筛选出来的ETF是否可以直接投资？
A: 筛选结果仅供参考，投资前请结合自身风险承受能力和投资目标。
