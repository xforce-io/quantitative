# 📊 统一投资顾问使用指南

## 🎯 概述

统一投资顾问 (`advisor.py`) 是一个整合了 **Smart Advisor** 和 **Investment Advisor** 功能的综合分析工具，提供四种分析模式：

- 🔍 **单标的深度分析** - 技术面 + 基本面 + 概率统计
- 📈 **投资组合策略分析** - 多标的组合分析和策略回测
- 🔧 **综合分析** - 深度分析 + 策略回测的完整分析
- ⚡ **批量分析** - 快速批量处理多个标的

---

## 🚀 功能特性

### ✅ Smart Advisor 核心功能
- **历史位置分析** - 基于历史高低点的位置判断
- **基本面估值分析** - PE/PB估值 + 盈利质量 + 成长性分析
- **概率统计分析** - 基于历史相似状态的概率预测
- **多维度风险评估** - 技术面风险的细化分析
- **综合投资建议** - 整合所有因素的决策支持

### ✅ Investment Advisor 核心功能
- **多策略回测** - MA/RSI/MACD/海龟等策略比较
- **CANSLIM分析** - 威廉·欧奈尔方法的基本面分析
- **多周期回测** - 3年/5年/10年等不同周期分析
- **投资组合管理** - 批量分析和组合优化

---

## 📖 使用方法

### 1. 🔍 单标的深度分析
**适用场景**: 对单只股票进行深度分析，获取详细的投资建议

```bash
# 基础分析
python advisor.py --mode single --symbol 002049.SZ

# 禁用基本面分析（仅技术分析）
python advisor.py --mode single --symbol 002049.SZ --no-fundamental

# 自定义历史数据天数
python advisor.py --mode single --symbol 002049.SZ --days-back 3000
```

**输出内容**:
- 📊 基本信息（价格、历史高低点）
- 📈 位置分析（历史位置百分比）
- 📊 技术指标（RSI、MACD、均线）
- 💰 基本面分析（PE、PB、成长性、盈利质量）
- 📈 概率统计（历史相似状态的概率）
- ⚠️ 风险评估（多维度风险评分）
- 🎯 投资建议（具体操作建议和理由）

### 2. 📈 投资组合策略分析
**适用场景**: 分析多个标的，进行组合投资决策

```bash
# 基本组合分析
python advisor.py --mode portfolio --symbols 002049.SZ,300661.SZ,603501.SH

# 半导体行业分析
python advisor.py --mode portfolio --symbols 002049.SZ,300661.SZ,603501.SH,688012.SH --portfolio semiconductor

# 从文件加载股票列表
python advisor.py --mode portfolio --symbols-file semiconductor_stocks.txt --portfolio semiconductor
```

**输出内容**:
- 📊 每个标的的详细技术面和基本面分析
- 📈 CANSLIM威廉·欧奈尔分析
- 🎯 综合评分和投资建议
- 📋 组合汇总（建议分布、风险分布、优选标的）

### 3. 🔧 综合分析 ⭐ **最强功能**
**适用场景**: 对单个标的进行最全面的分析，结合深度分析和策略回测

```bash
# 基本综合分析
python advisor.py --mode comprehensive --symbol 002049.SZ

# 自定义回测周期
python advisor.py --mode comprehensive --symbol 002049.SZ --periods 1Y,3Y,5Y,10Y

# 实际成功案例
python advisor.py --mode comprehensive --symbol 588000.SH --periods "1Y,3Y,5Y"  # 科创50ETF
python advisor.py --mode comprehensive --symbol 512480.SH --periods "1Y,3Y,5Y"  # 半导体ETF
```

**输出内容**:
- 🔍 完整的单标的深度分析
- 📈 多周期策略回测结果（1年/3年/5年等）
- 🎯 策略优选建议（最佳策略推荐）
- 🔧 综合投资建议（基于深度分析+策略回测）

### 4. ⚡ 批量分析
**适用场景**: 快速分析大量标的，进行筛选和对比

```bash
# 批量单标的分析
python advisor.py --mode batch --symbols 002049.SZ,300661.SZ,603501.SH,688012.SH

# 从文件批量分析
python advisor.py --mode batch --symbols-file semiconductor_stocks.txt

# 保存结果到文件
python advisor.py --mode batch --symbols-file semiconductor_stocks.txt --save results.json
```

**输出内容**:
- 📊 每个标的的完整分析
- 📈 批量汇总统计
- 🏆 投资机会排序
- ⚠️ 高风险警示列表

## 🚨 注意事项

### ⚠️ 分析限制
1. **基本面数据**: 仅支持A股，需要有效的财务数据
2. **技术分析**: 需要足够的历史数据（建议>200个交易日）
3. **指数分析**: 全球指数不支持基本面分析

### 📋 最佳实践
1. **先组合后单标的**: 用portfolio模式筛选，用single模式深度分析
2. **结合multiple timeframes**: 短期用single，长期用comprehensive
3. **定期更新**: 市场变化快，建议定期重新分析
4. **风险管理**: 重点关注风险评估部分，不要忽视风险提示

### 🔧 故障排除
- **数据获取失败**: 检查网络连接，或使用 `--no-cache` 强制更新
- **分析报错**: 可能是股票代码错误或数据不足
- **结果保存失败**: 检查文件路径权限
