# 投资组合估值分析功能说明

## 🎯 概述

投资组合分析器现已完整集成 **ETF/基金估值分析功能**，为USER_REAL_PORTFOLIO提供全面的估值维度分析。

---

## ✨ 新增功能

### 1. **价格分位数估值分析**

计算ETF/基金当前价格在历史价格中的位置：

- **1年分位数**: 过去252个交易日的价格分位数
- **2年分位数**: 过去504个交易日的价格分位数  
- **3年分位数**: 过去756个交易日的价格分位数
- **综合分位数**: 多周期平均分位数

**估值等级划分**:
- 0-10%: 极度低估 🟢
- 10-25%: 低估 🟢
- 25-40%: 偏低 🟡
- 40-60%: 合理 ⚪
- 60-75%: 偏高 🟡
- 75-90%: 高估 🔴
- 90-100%: 极度高估 🔴

### 2. **估值区间判断**

基于多周期均线（MA20/60/120/250）判断估值区间：

- **高估区**: 价格远高于长期均线
- **合理区**: 价格在均线附近波动
- **低估区**: 价格远低于长期均线

**均线排列状态**:
- 完美多头排列: 价格 > MA20 > MA60 > MA120 > MA250
- 震荡状态: 均线交织
- 完美空头排列: 价格 < MA250 < MA120 < MA60 < MA20

### 3. **均值回归信号**

基于布林带（20日均线 ± 2倍标准差）的偏离度分析：

**信号类型**:
- 🟢 **强烈买入信号**: 价格跌破下轨且远离均线
- 🟢 **买入信号**: 价格接近下轨
- 🟡 **观望/加仓**: 价格在均线下方但未到下轨
- ⚪ **持有**: 价格在均线附近（±5%以内）
- 🔴 **卖出信号**: 价格接近上轨
- 🔴 **强烈卖出信号**: 价格突破上轨且远离均线

**信号强度**:
- 强: 偏离均线超过10%
- 中等: 偏离均线5-10%
- 弱: 偏离均线小于5%

### 4. **估值汇总报告**

生成的Markdown报告中新增 **"💰 ETF/基金估值汇总"** 章节：

- 按估值水平自动分组
- **💚 低估机会**: 列出所有低估标的（适合买入）
- **⚠️ 高估警告**: 列出所有高估标的（建议观望/减仓）
- **✅ 合理估值**: 列出估值合理的标的

## 🔍 技术细节

### 数据要求

- **最少数据量**: 252个交易日（约1年）
- **适用范围**: ETF和公募基金（.SH/.SZ/.OF结尾）
- **不适用**: 个股（如002594.SZ比亚迪）使用表现评分替代

### ETF识别规则

系统自动识别以下代码格式为ETF/基金：
- **基金**: *.OF (如 019391.OF)
- **ETF**: 51xxxx.SH/SZ, 159xxx.SZ, 512xxx.SH, 513xxx.SH, 515xxx.SH, 516xxx.SH, 588xxx.SH

### 估值分析逻辑

```python
# 内部实现逻辑
def _analyze_symbol_valuation(symbol, data):
    # 1. 判断是否为ETF/基金
    if not _is_etf_or_fund(symbol):
        return {'applicable': False}
    
    # 2. 检查数据充足性
    if len(data) < 252:
        return {'applicable': False}
    
    # 3. 价格分位数分析
    percentile = valuation_analyzer.calculate_price_percentile(data)
    
    # 4. 均值回归信号
    mean_reversion = valuation_analyzer.calculate_mean_reversion_signals(data)
    
    # 5. 估值区间判断
    valuation_zone = valuation_analyzer.calculate_valuation_zone(data)
    
    return {
        'applicable': True,
        'valuation_level': '偏低',
        'percentile': 31.5,
        'zone': '低估区',
        'signal': '买入信号',
        ...
    }
```

## 💡 使用建议

### 投资决策参考

1. **低估机会（分位数<40%）**
   - ✅ 适合逢低布局
   - ✅ 长期持有价值高
   - ⚠️ 需结合基本面确认

2. **合理估值（分位数40-60%）**
   - ⚪ 正常持仓
   - ⚪ 等待更好时机
   - ✅ 定投可考虑

3. **高估警告（分位数>60%）**
   - ⚠️ 谨慎追高
   - ⚠️ 考虑部分止盈
   - 🔴 若>75%建议观望或减仓

### 配合其他指标

估值分析应与以下指标结合使用：
- ✅ 收益率表现（总收益/年化收益）
- ✅ 波动率（风险水平）
- ✅ Sleeve配置比例
- ✅ 市场环境判断

## 🐛 已知限制

1. **个股不支持**: 个股（如002594.SZ）不使用价格分位数估值，仍使用表现评分
2. **数据依赖**: 需要至少1年历史数据，新上市ETF无法分析
3. **市场环境**: 估值分析基于历史数据，不能预测未来
4. **基金特殊性**: 某些LOF基金可能数据获取困难

## ❓ 常见问题

**Q: 为什么某些标的没有估值信息？**
A: 可能是个股（不适用）或数据不足1年。

**Q: 估值"偏高"是否一定要卖出？**
A: 不一定。需结合趋势、基本面等综合判断。偏高（60-75%）可持有观察，高估（>75%）才建议减仓。

**Q: 如何解读"低估区 + 买入信号"？**
A: 这是强烈的买入机会信号，但仍需确认：1)基本面未恶化 2)有充足资金 3)符合资产配置计划。

**Q: 估值分析适用于所有市场环境吗？**
A: 在震荡市和熊市效果最好，牛市中估值参考意义相对较弱（可能持续高估）。
