# 完整策略发现和回测工作流程演示

本文档演示了如何使用智能交易 Agent 系统进行策略发现和回测的完整流程。

## 🎯 工作流程概览

整个流程分为两个主要阶段：
1. **策略发现阶段**：运行多个 Agent 实验，找到最佳策略参数
2. **回测验证阶段**：使用最佳策略进行长期回测，生成详细报告

## 📋 详细执行步骤

### 第一步：系统状态检查

首先确保系统配置正确：

```bash
python bin/run.py system status
```

### 第三步：运行策略发现实验

运行比亚迪多策略优化实验：

```bash
python bin/run.py trading agent run byd_multi_strategy
```

**系统会执行以下操作：**
- 生成 10 个不同配置的 Agent
- 每个 Agent 进行回测比较
- 自动选择最佳策略
- 保存实验结果到结构化目录

**关键输出摘要：**
```

收益率: 17.85%
夏普比率: 1.517

```

### 第四步：查看实验结果


### 第五步：执行长期回测

使用发现的最佳策略进行3年以上的回测：

```bash
python bin/run.py trading backtest-from-experiment data/expr/GridTrading_2506071704 \
    --start-date 2021-01-01 --end-date 2024-12-31 --initial-balance 200000
```

**回测参数说明：**
- `--start-date`: 回测开始日期（3年以上跨度）
- `--end-date`: 回测结束日期
- `--initial-balance`: 初始资金（可调整）

## 🎯 策略特点分析

### 网格策略优势
1. **震荡市获利**: 在价格震荡的市场中表现优异
2. **风险控制**: 通过基础仓位和网格仓位分离控制风险
3. **高胜率**: 实验中达到 100% 胜率
4. **参数优化**: 通过 Agent 系统自动找到最优参数组合

### 关键参数说明
- **网格层数 (8层)**: 提供充足的交易机会
- **网格间距 (1.5%)**: 平衡交易频率和单笔收益
- **基础仓位比例 (30%)**: 保持基本持仓，享受长期增长
- **网格仓位比例 (70%)**: 用于频繁交易获取震荡收益

## 🚀 高级用法

### 自定义回测参数

你可以在回测时覆盖任何参数：

```bash
python bin/run.py trading backtest-from-experiment data/expr/GridTrading_2506071704 \
    --start-date 2020-01-01 \
    --end-date 2024-12-31 \
    --initial-balance 500000 \
    --commission 0.0005 \
    --slippage 0.002
```

### 批量实验

可以依次运行多个实验进行对比：

```bash
python bin/run.py trading agent run byd_multi_strategy
python bin/run.py trading agent run cmb_conservative
python bin/run.py trading agent list-results
```

### 实验结果对比

查看所有保存的实验进行横向对比：

```bash
python bin/run.py trading agent list-results
```

## ✅ 最佳实践建议

1. **充分的时间跨度**: 建议使用3年以上的数据进行回测
2. **合适的初始资金**: 根据实际投资能力设置初始资金
3. **参数敏感性测试**: 运行多组实验对比参数影响
4. **市场环境考虑**: 在不同市场周期下验证策略稳定性
5. **风险控制**: 关注最大回撤和夏普比率等风险指标
